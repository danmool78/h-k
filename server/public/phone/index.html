찰랑 휴대폰 시연

실제 차가 없을 때 휴대폰을 흔들어 차 흔들림 대신 보냅니다. 차량 앱(에뮬레이터)과 웹 점검판(/app/)이 자동으로 "휴대폰 시연" 모드로 바뀝니다.

관리자 로그인
로그인하지 않음

이 계정은 아직 관리자가 아니에요.

  1. Firebase 콘솔 → Firestore → admins 컬렉션
  2. 문서 ID 에 아래 값을 넣고 빈 문서로 저장

저장한 뒤 이 페이지를 새로고침하세요.

잡는 법
  1. 평평하게 눕혀 휴대폰 위쪽을 차 앞으로, 또는 거치대에 세워 화면이 운전자 쪽으로 (시작할 때 놓인 자세를 알아서 찾아요 — 시작한 뒤엔 돌리지 마세요)
  2. 브레이크·출발처럼 앞뒤로, 굽은 길처럼 좌우로 밀었다 당기기
  3. 위아래로 들었다 내리면 방지턱·오르내리는 길, 앞을 살짝 들면 오르막 (시작할 때 기울기를 평지로 봐요)
  4. 2~10초에 한 번 정도로 천천히 — 멀미를 일으키는 흔들림이에요. 빨리 흔드는 떨림은 물컵이 거의 반응하지 않아요
