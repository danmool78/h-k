# 기획서 초안 — 안기다려

> 접수양식 "02 앱 프로젝트 소개 / 심사 자료" 항목 순서대로 작성.
> 〔 〕 표시는 11/2 이후 실측 데이터로 채울 값.

**앱명 / 프로젝트명:** 안기다려 — 기다리지 않는 충전 경로

---

## 1. 앱 한 줄 소개

내비에 목적지만 입력하면, 전국 고속도로 충전기의 실시간 상태와 혼잡 이력으로 **"도착했을 때 기다리지 않을 충전소"**를 골라 내비 경유지로 넣어 주고, 주행 중 그곳이 붐비면 더 빠른 곳으로 바꿔 주는 **Pleos 내비 플러그인 앱**입니다.

## 2. 기획 배경

**전기차 장거리 운전자의 진짜 불편은 "못 가는 것"이 아니라 "휴게소에서 기다리는 것"입니다.**

- 차량 내비는 이미 도착 시 예상 배터리와 경로상 충전소(대수·출력)를 알려 줍니다. 하지만 그 충전소가 **내가 도착할 때 비어 있을지**는 알려 주지 않습니다.
- 그래서 운전자는 휴게소에 들어갔다가 충전기가 모두 사용 중이면 20~30분을 기다리거나, 다음 휴게소까지 불안하게 달립니다. 숙련된 운전자는 "한산한 지방 휴게소까지 가서 내일 쓸 만큼 넉넉히 충전"하는 감을 갖고 있지만, 대부분은 그 판단을 할 정보가 없습니다.
- 실제로 저희가 수집한 데이터로 보면, 평일 오후 한 시점에도 전국 고속도로 휴게소 624곳 중 **72곳(약 12%)이 만차**였습니다. 〔주말·연휴 오후 만차 비율: 실측 후 기재〕
- 반대로 "겨우 도착할 만큼만" 충전하면 다음 날 일정이 불편해집니다. 운전자에게 필요한 건 **"어디서, 몇 %까지, 몇 분 충전하면 기다리지 않고 넉넉히 도착하는가"**에 대한 숫자로 된 답입니다.

## 3. 앱 주요 기능 및 차량 특화 요소

### 핵심 기능

| 기능 | 내용 |
|---|---|
| **① 목적지 입력 시 자동 추천** | 내비에 목적지를 입력하는 순간 앱이 경로를 읽고, 경로상 충전소 중 "도착 시점에 비어 있고 총 소요시간이 가장 짧은 곳"을 알림으로 제안. 한 번 누르거나 음성으로 내비 경유지에 반영 |
| **② 도착 시점 대기 예측** | 전국 급속 충전기 5만여 대의 실시간 상태(5분 수집) + 휴게소별 요일·시간대 혼잡 이력으로, 지금이 아니라 **내가 도착할 시각의 대기 시간**을 예측 |
| **③ 주행 중 자동 재계획** | 가던 충전소가 만차·고장이 되면 음성으로 알리고 더 빠른 곳으로 경유지 변경. 더 나은 곳이 생기면 "선산휴게소로 바꾸면 12분 빨라집니다. 바꿀까요?"라고 물음 |
| **④ 넉넉한 도착 보장** | "도착 시 최소 배터리"(기본 30%)를 정하면, 운이 나쁜 경우에도 그 이상 남도록 충전량을 계산 — 겨우 도착해서 다음 날 고생하지 않게 |
| **⑤ 불확실성까지 보여주는 예측** | 같은 여행을 2,000번 미리 계산(몬테카를로)해 "보통 21:19 · 운 나쁘면 22:15 도착", "98% 확률로 30% 이상 남김"처럼 범위로 안내 |
| **⑥ 차량·운전자별 학습** | 주행할수록 이 차의 소모 특성, 운전 습관(출퇴근·장거리·밤·비·눈별), 충전 속도를 학습해 예측 범위가 좁아짐. 학습 정도를 게이지로 표시 |
| **⑦ 음성으로 묻고 답하기** | Gleo AI: "안기다려, 어디서 충전해?", "근처에 빈 급속충전기 있어?", "바꿔줘" |

### 차량 특화 요소 — 폰 앱으로는 할 수 없는 것

- **내비와 하나처럼 동작:** Pleos 내비의 목적지·경로·도착 예상 배터리를 읽고, 경유지를 직접 추가·교체합니다. 운전자 입장에서는 **"내비가 똑똑해진 것"**처럼 느껴집니다.
- **차량 데이터로 자동 계산:** 배터리 잔량과 용량, 탑승 인원(좌석 감지), 공조 상태와 설정 온도, 타이어 공기압, 주행 모드를 차에서 직접 읽어 입력 없이 계산합니다.
- **내비 실시간 정보 위에 더하기:** 주행 시간과 소모는 실시간 교통이 반영된 내비 예측을 기준으로 삼고, 내비가 모르는 **충전소 대기와 불확실성**만 더합니다. 사고·정체로 내비 예측이 바뀌면 우리 계획도 즉시 다시 계산됩니다.
- **주행 중에만 의미 있는 판단:** 달리는 동안 충전소 상태 변화를 감시하고 경로를 바꾸는 것은 차 안에서만 가능한 경험입니다.

## 4. 주요 사용 시나리오

**금요일 오후 5시, 서울에서 부산으로 출발하는 아이오닉 5 운전자 (배터리 70%)**

1. **출발 전** — 평소처럼 내비에 "부산"을 입력합니다. 화면 위로 알림이 뜹니다.
   > 칠곡휴게소에서 15분 충전 → 21:40 도착 · 내비 추천 문경휴게소 대신 가면 12분 빠름
   > 30분 뒤 출발하면 휴게소가 덜 붐벼 총 18분 단축
   알림을 누르거나 "안기다려, 그걸로 해줘"라고 말하면 칠곡휴게소가 경유지로 들어갑니다.
2. **주행 중** — 운전자는 아무것도 하지 않습니다. 앱이 몇 분마다 칠곡휴게소 충전기를 확인합니다. 두 시간 뒤 충전기가 모두 차자 음성이 나옵니다.
   > "칠곡휴게소 충전기가 모두 사용 중입니다. 선산휴게소로 바꾸면 12분 빨리 도착합니다. 10초 뒤 경유지를 변경합니다."
3. **충전소 도착** — 빈 충전기에서 바로 충전합니다. "75%까지 약 18분"이 표시됩니다.
4. **도착** — 예측 21:40, 실제 21:43. 이번 주행이 학습되어 다음 예측이 더 정확해집니다.
5. **평소 출퇴근** — 충전이 필요 없으면 조용합니다. 궁금하면 "안기다려, 집까지 충분해?" → "충분합니다, 도착 시 62%".

**차 밖에서 (자체 서비스)** — 전날 밤 "내일 부산, 언제 출발하지?"를 미리 보고, 시간대별 총 소요 비교로 출발 시각을 정합니다. 전국 휴게소 실시간 혼잡 지도도 볼 수 있습니다.

## 5. 개발 계획

### 구성

```
[Pleos Connect 차량]                                [H-Y Server]
 안기다려 앱 (Kotlin, Jetpack Compose)   ←→   Firebase Cloud Functions (서울 리전)
  ├ 추천 화면 / 배터리 여정 / 학습도              ├ 충전소 수집: 환경공단 실시간 API (5분)
  ├ 주행 학습 서비스 (차량 값 10초 수집)          ├ 혼잡 통계: 휴게소별 요일·시간대 사용률
  ├ 경유지 감시 서비스 (주행 중 재계획)           ├ 상태 이력: 휴게소 충전기 5분 단위 기록
  └ Gleo 음성 연동                                ├ 도로 경로: OSRM / 날씨: Open-Meteo
                                                  └ 예측 검증: 이력 예측 vs 실제 상태
```

### Pleos SDK·API 사용 계획

| SDK | 사용 기능 | 용도 |
|---|---|---|
| **Vehicle SDK** | EvBattery(SOC·잔량·용량), Odometer(주행거리·주행가능거리), Seat(탑승 감지), HVAC(공조 상태·설정 온도), Tire(공기압), DrivingMode | 입력 없는 소모 계산, 주행 학습 |
| **NaviHelper SDK** | 목적지·현재 위치 조회, 목적지 변경 이벤트, 경로 계산(도착 예상 배터리·경로상 충전소·충전 계획), 경유지 추가·삭제, 경유지 도착 이벤트 | 목적지 입력 시 추천, 경유지 반영, 주행 중 재계획 |
| **Gleo AI (App Schema)** | CHECK_ARRIVAL_CHANCE, RECOMMEND_CHARGING_STOP, FIND_NEARBY_CHARGER | 음성 질문·경유지 변경 |
| **TextToSpeech SDK** (예정) | 음성 안내 | 현재 Android TTS → Pleos TTS로 전환 예정 |

## 6. 기대효과 및 발전 가능성

### 사용자 가치 〔실측 후 숫자 확정〕

- **대기 시간 절약:** 기록된 실제 충전기 상태로 같은 경로를 "빈자리를 모르는 방식"과 비교 재현한 결과, 〔평균 N분 / 주말 오후 최대 N분〕 빨리 도착
- **예측 정확도:** 도착 시각 예측 오차 〔빈자리를 모르는 방식 N분 → 안기다려 N분〕
- **불안 해소:** "운이 나빠도 30% 이상 남는다"는 확률로 장거리 주행 불안을 줄임

### 타깃 고객

- **1차:** Pleos Connect 탑재 현대·기아 전기차 중 **월 1회 이상 장거리(100km+) 주행**하는 운전자 — 명절·주말 귀성, 출장, 여행
- **2차:** 렌터카·카셰어링·법인 차량 등 **충전 대기가 곧 비용**인 전기차 운영사

### 예상 MAU · Retention (가정 기반)

- 앱이 내비와 함께 **자동으로 동작**하므로(목적지 입력 시 알림) 별도로 앱을 여는 습관이 필요 없습니다. MAU는 "한 달에 한 번 이상 추천을 받은 운전자"로 정의합니다.
- 〔Pleos 탑재 전기차 대수 × 설치율 × 월 장거리 주행 비율로 산정 — 탑재 대수 공개 자료 확인 후 기재〕
- Retention: 출퇴근 단거리에서도 학습·음성 질문이 동작하고, 장거리 때마다 실질적인 시간 절약을 체감하므로 설치 후 이탈 요인이 적음. 〔목표: 3개월 유지율 N%〕

### 발전 가능성

1. **Pleos 앱으로 실차 검증** → 운전자별 학습 데이터와 실측 절약 효과 축적
2. **내비 연동 엔진(API):** 충전 판단 엔진은 서버 API 형태라 현대·기아 내비의 EV 경로 플래너에 그대로 붙일 수 있음 — "직접 만드는 대신, 검증된 엔진과 쌓인 데이터를 가져가는 것이 빠른" 구조
3. **해외 확장:** 충전소 데이터 연결부를 나라별 교체형(OCPI 기반)으로 설계. 한국은 공공 데이터로 검증, 해외는 현대·기아 충전 서비스 데이터 등을 연결
4. **충전 사업자·운영사 연계:** 혼잡 예측 데이터를 충전 사업자의 수요 분산, 운영사의 충전 스케줄링에 제공
