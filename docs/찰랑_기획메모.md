# 찰랑: 아이가 멀미하지 않는 운전 (기획 메모)

> 작성 2026-10-29 · 현대·기아 차량용 앱 공모전 출품작 (패밀리·동승자 케어 / 안전 운전)
> 접수 마감 2026-11-15, 2차 실연 심사 2026-12-03~04 (실제 동작하는 앱 필요)

## 한 줄 소개

화면에 물컵 하나를 띄우고, 물이 넘치지 않게 운전하면 아이가 멀미하지 않는다.

## 핵심 개념

1. **물컵:** 차의 앞뒤·좌우 가속도에 따라 물이 출렁인다. 물이 넘치지 않게 운전하는 것이 목표
2. **넘친 양 = 멀미 누적량:** 넘친 양을 계속 쌓는다. 부드럽게 달리거나 쉬면 천천히 줄어든다 (몸의 회복)
3. **물 높이 = 우리 아이 기준 (앱에서 보호자가 설정)**
   - 멀미는 개인차가 매우 커서 일반 기준이나 미리 녹화한 데이터로는 맞출 수 없다
   - **앱에 녹화기가 들어 있다:** 주행하는 동안 흔들림(물컵 출렁임·넘친 양)을 계속 기록한다. 별도 장비·사전 녹화 없음
   - 처음에는 평균 기준으로 시작하고, 주행 중 아이가 멀미할 때 보호자가 "지금 멀미" 버튼(또는 음성)을 한 번 누르면 기록에서 그 시점의 누적량을 찾아 물 높이를 다시 정한다. 단순하게: 버튼 하나
   - 다음 주행부터는 그 기준에 닿기 전에 경고 → 쓸수록 우리 아이에게 맞춰진다
   - 아이가 여럿이면 아이별로 저장(아이마다 자리 지정), **좌석 탑승·안전벨트로 누가 탔는지 보고 물 높이 자동 설정**. 둘이면 더 예민한 아이 기준, 모르는 동승자는 보통 기준, 혼자면 끔. 벨트를 안 맨 좌석은 짐으로 본다
4. **경고:** 누적량이 기준에 가까워지면 단계별로 알림
   - 주의: "찰랑" 소리 + "다음 구간은 부드럽게"
   - 위험: "아이 멀미 위험이 높아요. 15km 앞 휴게소에서 쉬어 가세요" → 원하면 내비 경유지 추가
   - 자주 넘침 (누적 0.5, 또는 3분 안에 4번 넘치고 누적 0.25): **차가 직접** 외기 유입·에어컨·온도 2℃ 낮춤·풍량 +1, 아이 옆 창문 25%는 **먼저 물어보고** 연다 (시속 80km 이하·와이퍼 꺼짐일 때만, 고속·비면 다시 닫음). 먼지 나는 길이라 거절하면 내부 순환 + 공기청정으로 바꾸고 다시 묻지 않음. 회복되면 원래 값으로 되돌림
5. **운전 습관 학습:** 이 운전자가 어디서 많이 넘치는지 (진출로, 신호 출발, 굽은 길 등) → 내비 다음 안내와 합쳐 미리 예고
6. **도착 후 리포트:** 어디서 얼마나 넘쳤는지 지도, 아이 편안함 점수

## 과학적 근거

- ISO 2631-1은 멀미 위험을 흔들림을 시간에 걸쳐 누적한 **멀미 누적량(MSDV, Motion Sickness Dose Value)** 으로 본다
- 0.1~0.5Hz(2~10초 주기)의 느린 흔들림이 멀미를 가장 잘 일으킨다 (가다 서다, 굽은 길에서 계속 핸들을 돌릴 때)
- **구현: 물 기울기 = ISO 2631-1 Wf 가중 가속도** (표준 전달 함수, 공개 구현 janiex/SimulinkMatlab 의 매개변수·표준 가중값 표와 0.02~2Hz 0.25%, 전체 1% 안에서 일치). 수식·근거 정리: h-y-server.web.app/admin/
- 기록에서 표준 MSDV 와 흔들림 주기(가장 센 주기, 멀미에 가장 영향을 준 주기, 2~10초 비율)를 계산한다
- 주의: 표준 Wf·MSDV 는 수직 흔들림 기준. 차량(수평) 적용은 연구 관행이므로 기획서에는 해당 논문을 찾아 인용할 것
- 물컵의 출렁임 주기를 이 대역에 맞추면 "넘친 양 ≈ 멀미 누적량"이 된다
  → 발표: "물컵은 비유이고, 속은 국제 규격의 멀미 지표. 기준점만 우리 아이에게 맞춘다"
- 기획서에 쓰기 전에 규격 원문·논문 수치를 다시 확인할 것

## 신호

Pleos Playground에서 지금 쓸 수 있는 SDK는 **Vehicle State, NaviHelper 두 가지뿐**이다 (2026-10-29 기준 FusedLocation·TTS·STT·Vehicle Control은 "Coming Soon").
→ 핵심 기능은 이 두 SDK만으로 만든다. 에뮬레이터·공모전 단계는 권한 선언만으로 사용 가능 (승인은 App Market 등록 때).

Vehicle SDK 2.3.2 (SDK 파일 직접 확인) + `CAR_DRIVE` 권한 문서 (주행 중 호출 제한 없음):

| 필요한 값 | 출처 |
|---|---|
| 속도 | 주행 거리 변화 (`getTripInstantaneousDrivingDistance`, `getCurrentDistanceDriven` + 변화 알림) ÷ 시간 |
| 앞뒤 가속도 | 속도 변화 + 브레이크 페달 (밟음/안 밟음, 감속 시작 감지) |
| 좌우 가속도 ① | 속도² × 곡률. 곡률은 **전륜 조향각** (`getCurrentSteeringWheelAngle`, 바퀴 각도라 조향비 불필요) ÷ 축간거리 |
| 좌우 가속도 ② | 속도 × 방향 변화율. 방향은 NaviHelper 현재 위치의 `heading` (①과 교차 확인) |
| 앞으로 올 움직임 | NaviHelper 회전 안내 `TBTInfo`(종류·남은 거리·설명), 주의 지점 `CautionPoint`(종류·남은 거리) |
| 아이 탑승 | 좌석별 탑승·안전벨트 (Seat) |
| 속도·가속도 직접 값 | 없음 |

확인할 것: 주행 거리 값이 들어오는 간격과 단위 (0.1km 단위면 속도가 너무 거칠다 → 보정·위치 기반과 섞기)

설계: 물컵 계산은 "앞뒤·좌우 가속도"만 받게 하고, 그 값을 가져오는 곳(`MotionSource`)을 바꿔 끼울 수 있게 한다.
- 실제 차가 가속도를 주면 그대로
- 안 주면 조향각 + 속도로 추정
- 시연은 주행 시나리오 재생 (실제 도로 모양으로 만든 굽은 길·진출로·가다 서다). 차가 없고 에뮬레이터에는 실제 움직임이 없으므로 실연 심사에서도 이 방식이 가장 안정적

## 안전 설계 (운전 중 화면 주시 방지)

- 주행 중 화면은 한눈에 보이는 단순한 물컵 하나. 숫자·글자 없음
- 주된 피드백은 소리 ("찰랑")
- 자세한 점수·지도는 도착 후
- 뒷좌석 아이가 자기 화면으로 같이 보는 방식도 검토 (아이에게는 놀이)

## 쓰는 SDK

| SDK | 용도 | 신청 |
|---|---|---|
| Vehicle | 조향각, 브레이크, 주행 거리, 좌석 탑승·벨트, 와이퍼 / 제어: 공조(내외기·에어컨·온도·풍량), 창문 위치 | 조회 불필요, 제어(Vehicle Control) 필요 — 에뮬레이터·공모전 단계는 권한 선언으로 동작 |
| NaviHelper | 현재 위치·진행 방향, 다음 회전 안내, 주의 지점, 휴게소 경유지 추가 | 불필요 |
| TextToSpeech / SpeechToText | 경고 안내, "지금 멀미" 음성 입력 — 아직 Coming Soon → 안드로이드 기본 TTS·Gleo로 대체 | 필요 |

## 진행 순서

1. 이 기획 메모 ✅
2. 물컵 출렁임 계산 + 멀미 누적량 계산, 주행 시나리오 재생으로 검증 (화면 없이) ✅
3. 물컵 화면 + 경고 (소리, 휴게소 제안) + "지금 멀미" 기준 맞추기 ✅
4. 실제 신호 연결: 좌석·벨트 → 물 높이 자동, 공조·창문 제어, 조향·브레이크·주행 거리, 내비 회전 안내 ✅ (코드 완료, 에뮬레이터 확인 필요)
5. 아이별 기준 저장 ✅, 운전 습관 학습, 도착 후 리포트
6. 기획서 (접수양식), 시연 영상
