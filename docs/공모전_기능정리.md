# 찰랑 — 공모전 지원서용 기능 정리

> 지원서·발표 자료를 쓸 때 이 문서를 출발점으로 쓴다. 기능마다 **무엇을 / 왜 특별한가 / 어떤 차량 데이터·근거 / 어디서 보나** 순서.
> 수식·매개변수·검증은 관리자 페이지 https://h-y-server.web.app/admin/ (`server/public/admin/index.html`) 에 장 번호로 정리되어 있다.
> 마지막 정리: 2026-10-30

## 한 줄 소개

화면에 물컵 하나. 물이 넘치지 않게 운전하면 아이가 멀미하지 않는다 — 물컵은 비유이고, 속은 국제 규격(ISO 2631-1)의 멀미 지표다.
차량 데이터로 누가 탔는지 보고, 가는 길의 멀미 위험을 미리 알려 주고, 멀미가 쌓이면 차가 직접 환기하고, 끝나면 운전을 평가한다.

## 왜 필요한가 (문제)

- 아이 멀미는 흔하고 개인차가 크다. 부모는 "얼마나 부드럽게 운전해야 하는지" 기준이 없다.
- 멀미는 순간이 아니라 **쌓이는** 것(MSDV)이라 운전자가 체감하기 어렵다.
- 그래서 "넘치는 물" 이라는 누구나 아는 감각으로 바꿔 보여 준다.

## 기능 목록

### A. 핵심: 물컵 = 멀미 지표

| 기능 | 내용 | 근거·검증 (admin 장) |
|---|---|---|
| ISO 2631-1 Wf 물컵 | 물 기울기 = 차의 앞뒤·좌우·위아래 가속도에 ISO 2631-1 멀미 가중 Wf 를 건 값. 0.16Hz(약 6초 주기)에서 가장 크게 출렁인다 | 공개 구현 janiex/SimulinkMatlab 의 표준 가중값 표와 0.02~2Hz 0.25%, 전체 1% 안 일치 (3장) |
| 넘친 양 = 멀미 누적량 | 넘친 양을 쌓고, 넘치지 않으면 10분마다 1/e 로 회복 (몸의 회복) | 시나리오로 값 결정 — 부드러운 운전 0.00, 거친 운전 1.43(위험) (4장) |
| 위아래(z) 흔들림 | 방지턱·오르내리는 길도 Wf 로. 둔덕을 넘을 때 물이 떠서 더 기욺 (유효 중력 g+az) | 4-1장 |
| 길 경사 | 오르막·내리막에서 물은 수평 유지 → 컵 안에서 기울어 보임 (경사는 멀미가 아니므로 넘침에는 안 넣음). 비탈에서 출발해도 내비 경로의 실제 도로 높이로 센서 0 점을 달리며 바로잡음 (지도 없으면 긴 평균). 화면 기기에 센서가 없어도 길 안내 중이면 지도 경사로 수면이 기욺 | 4-1장 |
| 진짜 3D 물 | GPU 셰이더(앱·웹 같은 코드)로 유리·굴절·반사·빛 무늬, 48×48 얕은 물 파동 방정식으로 물결이 벽에서 튀고 서로 부딪힘. 방지턱에서 수면이 튐 | 9·9-1장 |

### B. 우리 아이에게 맞추기 (학습)

| 기능 | 내용 | 근거 |
|---|---|---|
| "지금 멀미" 버튼 | 이번 주행 기록을 다시 재생해 그 순간 위험 기준에 닿도록 아이의 물 높이를 맞춤. 다음부터 멀미 전에 경고 | 5장 |
| 아이별 민감 주기 학습 | 멀미 직전 유독 많았던 흔들림 주기를 쌓아(3번부터) 그 주기를 최대 1.5배 강조 — "민지는 5초 흔들림에 약해요" | 5-1장 |
| 좌석으로 누가 탔는지 | 좌석 탑승·안전벨트로 아이를 알아보고 그 아이 기준을 자동 적용. 여럿이면 가장 예민한 아이, 혼자면 물컵 쉼 | 6장 |

### C. 차가 직접 돌본다 (차량 제어)

| 기능 | 내용 |
|---|---|
| 자동 환기 | 자주 넘치거나 누적이 쌓이면 외기 유입·에어컨·온도 2도↓·풍량+1, 회복되면 원래 값으로 |
| 창문은 물어보고 | 아이 옆 창문 25% 를 **먼저 묻고** 연다 (시속 80km 이하·비 안 올 때). "먼지 · 닫기" 를 고르면 내부 순환+공기청정 |
| 고속·비 | 시속 90km 초과나 와이퍼 작동이면 창문을 다시 닫음 |
| 휴게소 안내 | 위험 수준이면 "8km 앞 휴게소에서 쉬어 가세요" |
| 내비 예고 | 진출로·유턴·방지턱 앞에서 "곧 진출로예요. 천천히 부드럽게" |

### D. 가는 길을 미리 (출발 전)

| 기능 | 내용 | 근거 |
|---|---|---|
| 멀미 위험 구간 미리보기 | 모든 길에 같은 물리 기준: 실제 도로 모양(굽이·높이·방지턱·서는 곳)을 편하게 달릴 때의 흔들림을 만들어 물컵·주행 평가와 같은 ISO 2631-1 Wf 로 1km 마다 평가, 그 1km 만 달렸을 때 주행 평가 70점 미만 = 조심, 50점 미만 = 위험 (내비가 안내를 어떻게 나누든 결과가 같음) → 위험·조심 구간, 출발 때 요약, 구간 1.2km 앞에서 다시 알림, 위험 구간 앞 휴게소 권유 | 6-2장 |
| 3D 경로 브리핑 | 출발 전(정차 중) 가는 길을 3D 로: 전체를 한 바퀴 돌며 보여 주고 → 위험 구간만 차례로 "여기서 여기까지" 짚고 → 그 구간으로 빨려 들어가 그 구간만 실주행 20배로 달려 보고 → 올라옴. 40초 안. 말로도 설명 | 6-4장 |
| 실제 지형 | 공개 고도 타일로 경로 둘레 산·골짜기를 높이별 색과 그림자로, 위험 구간은 50m 간격으로 자세히 | 6-4·6-5장 |
| 실제 도로 모양 | 지금 위치 → 목적지 실제 도로(OSRM)로 굽이·편안한 속도 계산 | 6-5장 |

## 안전 설계

- 주행 중 화면은 물컵 하나, 주된 피드백은 소리("찰랑")와 짧은 음성
- 분석 화면·브리핑은 주행 중 열리지 않음 (정차·시연에서만)
- 창문은 묻고 연다, 고속·비면 닫는다, 혼자면 아무것도 안 함
- 아이 정보·주행 기록·설정은 기기 안에만

## 과학적 근거 (지원서 인용 후보)

- ISO 2631-1:1997 — Wf 주파수 가중, MSDV, 부록 D 멀미 비율(Km≈1/3)
- 0.1~0.5Hz(2~10초 주기) 흔들림이 멀미를 가장 잘 일으킴
- **확인 필요**: Wf·MSDV 는 원래 수직 기준 → 차량 수평 적용 연구 논문을 찾아 인용 (admin 11장 "한계와 확인할 것")

## 검증 (자동 테스트, GitHub Actions 에서 매번)

Wf 표준표 대조, 물컵·누적, 기준 맞추기, 차량 조치 규칙, 기록·지연, 흔들림 주기, 민감 주기 학습, 위아래·경사·기기 방향 찾기, 주행 평가, 가는 길 미리보기, 경로 선, 실제 지역 시연 길, 브리핑 시간, 설정 (admin 10장 표)

| 항목 | 값 |
|---|---|
